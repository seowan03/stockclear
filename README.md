# 📦 StockClear

> **기업의 숨은 자금을 찾아주는 스마트한 재고 파트너**

**StockClear**는 기업의 재고 데이터를 분석하여 장기재고 및 악성재고를 식별하고,
재고 위험도를 시각화하여 **효율적인 재고 처분 전략을 추천하는 재고 관리 플랫폼**입니다.

---

## 팀구성
- 팀장: 임서환 
- 팀원: 김태호
- 팀원: 이병우
- 팀원: 박지훈
- 팀원: 양상명


## 📌 프로젝트 소개

기업에서는 판매가 지연되는 재고가 장기간 보관되면서

- 보관 비용 증가
- 자금 회수 지연
- 상품 가치 하락
- 재고 관리 비효율

등의 문제가 발생할 수 있습니다.

StockClear는 사용자가 보유한 **Excel/CSV 재고 데이터를 업로드**하면
데이터를 기반으로 재고 상태를 분석하고 위험도를 분류합니다.

또한 LLM을 활용하여 분석 결과를 바탕으로 상품별 **재고 처분 전략**을 제공합니다.

---

## 🎯 프로젝트 목표

1. Excel/CSV 형태의 재고 데이터를 간편하게 업로드
2. Pandas를 활용한 재고 데이터 분석
3. 상품별 재고 위험도 자동 분류
4. 분석 결과를 대시보드에서 직관적으로 제공
5. LLM을 활용한 상품별 처분 전략 추천
6. 재고 보관 비용 및 자금 회수 지연 문제 개선
